# 검색·추천 UI 개선 (2026-10-15)

## 변경 내용

- 상단 전체 검색은 관광 API를 새로 조회하며 현재 지도 영역이나 카드 목록에 한정하지 않는다. 선택한 지역·시군구·유형 조건은 유지한다.
- KMP 검색·병합 정렬은 불러온 목록 안에서만 동작하므로 메뉴 이름과 설명을 분리했다.
- 추천은 선택 지역에서 선호 유형 및 담은 장소 유형별 최대 100곳을 별도 조회한다. 후보 총수와 실제 비교 수를 표시하며 전체 관광 데이터의 전수 비교는 아니다.
- 초록색 추천 영역과 `추천 N` 순위로 일반 검색 카드와 구분한다.
- 모든 검색 카드에 사진 유무와 관계없이 번호를 표시한다.
- 제목순 24곳을 최근 수정순 60곳으로 변경하고 더 보기로 추가 조회한다. 내 주변 검색은 거리순이다.
- 데스크톱 사이드바를 넓히고 검색부 간격을 줄였다.

## 검증

`npm run build`, `npm test` 통과. Java 2,064개·브라우저 알고리즘 2,014개·추천 212개 검사와 새 후보 조회 통합 검사(지역 전달, 지도 외 후보, 유형별 상한, 중복 제거, 부분·전체 실패, 샘플 모드)를 실행했다.

로컬 샘플 브라우저에서 추천 1 순위·일치도·이유 표시와 일반 결과 제목·번호를 확인했다. 운영 검증 결과는 아래와 같다.


## 운영 실데이터 확인

- GitHub CI와 Cloudflare Pages 배포 성공 (코드 5e1a7e4).
- 전국 49,614곳 중 60곳 표시, 더 보기 후 120곳. 첫 카드 제목은 단양관광호텔·하동 화개장터 등으로 제목순 편중 해소.
- 첫 60개 카드 전체에 번호 표시. 그중 사진이 있는 58개 카드도 번호 유지.
- 전체 이름 검색 `경복궁`: 13곳. 목록 내 `종로` + `한복남 경복궁점` 거리 기준: 9곳.
- 해당 검색 상태에서 문화시설 추천: 전국 조회 대상 2,766곳 중 후보 100곳, 추천 5곳. GS칼텍스 예울마루·나주문화원 등 검색 목록 밖 장소를 반환.
- 데이터 개수와 장소는 API 갱신에 따라 달라질 수 있다.
