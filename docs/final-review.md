# 최종 점검 기록

## 확인한 범위

- 정적 JavaScript 검사와 배포 빌드 통과.
- 게시판·공지 작성/상세/수정/삭제, 새로고침 직접 주소, 뒤로 가기, 삭제된 글 안내 통과.
- 비회원 찜 저장/재접속/삭제, 로그인 후 Hotplace 자동 입력 및 등록 통과.
- 로그인 후 게시글 작성 이어가기, 로그아웃 후 작성자 버튼 제거 통과.
- 찜 시 지도 중심/확대 수준 유지, 카테고리 즉시 검색, 검색·페이지 전환 통과.
- 탈퇴 후 개인 초안 제거와 같은 아이디 재가입 시 빈 여행계획 확인.
- 7개 페이지 데스크톱 1280px·모바일 390px에서 가로 넘침과 실행 오류 없음.
- 실제 관광 API 지역·시군구·키워드·상세 응답과 Kakao 지도 타일 표시 확인.

브라우저 자동 검증은 별도 테스트 컨텍스트에서 실행했으며 배포 서비스의 사용자 저장소에 테스트 데이터를 넣지 않았습니다. 오류 처리와 화면 검증 일부는 API를 차단해 샘플 모드로 검사했습니다.

## 수정한 문제

- 찜·여행 추가/제거 시 검색 지도로 자동 이동하던 흐름을 수정.
- 이전 주소 검색 결과가 새 검색 마커에 섞일 수 있는 비동기 경쟁을 차단.
- 비회원 글쓰기에서 로그인 후 작업을 이어가도록 연결.
- 로그아웃 후 현재 게시글의 수정/삭제 버튼을 즉시 갱신.
- 중복 이메일 가입과 프로필 변경을 차단.
- 회원 탈퇴 시 개인 초안 정리 및 공개 글 작성 권한 해제.
- Hotplace 방문일에 미래 날짜를 입력하지 않도록 제한.
- 새 clone에서 필요한 키 파일 템플릿과 실행 절차 추가.

## 제출 시 설명할 제한

실제 서버 인증·DB·기기 간 데이터 동기화는 없다. 회원과 게시판은 현재 브라우저 기반 시연 기능이다. 공지 관리자 역할, 뉴스 수집, 날씨 등 선택 기능은 미구현이다. API 장애 시 샘플 안내를 표시하며 지도 경로는 도로 길찾기가 아니다. GitHub 배포 브랜치만 Cloudflare와 연결되어 있고 GitLab은 제출용이다.
