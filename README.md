# EnjoyTrip

공공데이터를 활용한 국내 여행 탐색 서비스. `자바전공_enjoytrip_16_03_프론트.pdf`의 필수 요구사항과 여행계획·Hotplace·커뮤니티 기능을 HTML5, CSS3, JavaScript로 구현했습니다. Bootstrap 5.3.3을 사용하며 작은 화면에서도 동작합니다.

## 실행

프로젝트 루트에서 다음 명령을 실행하고 http://localhost:8001 으로 접속하세요.

```powershell
python run.py
```

VS Code Live Server로 `index.html`을 열어도 됩니다. ES 모듈과 브라우저 저장/암호화 기능을 사용하므로 파일 더블클릭 대신 localhost 서버에서 실행하세요.

## API 설정

`01_api/js/keys.js`에 본인의 `DATA_GO_KR_API_KEY`(공공데이터포털 서비스 키)와 `KAKAO_MAP_KEY`(카카오 JavaScript 키)를 설정합니다. 카카오 개발자 콘솔에서 실행 주소(예: `http://localhost:8001`)를 허용 도메인으로 등록하고 지도 사용 권한을 확인하세요. 기존 키 값은 수정하지 않았습니다. 키를 포함한 파일은 공개 저장소에 올리기 전에 확인하세요.

관광정보는 기존 예제의 한국관광공사 `KorService2`를 활용합니다. 지역코드·시군구·관광 유형, 키워드, 현재 위치 반경 2km 조회를 지원합니다. 결과는 24개 단위로 더 볼 수 있습니다. 서비스 키 인코딩과 빈 결과·서버 오류·요청 시간 초과를 처리합니다.

API 연결이 실패하면 **샘플 모드**라는 안내와 함께 프로젝트 내 예시 데이터만 표시합니다. 샘플은 실제 API 응답이 아니며 숙박·음식점·코스 예시를 포함합니다. 지도 SDK가 실패하면 원인 안내와 외부 카카오맵 링크를 제공합니다. 정확한 장소·축제 일정·영업정보는 공식 안내를 확인하세요.

## 사용 흐름

1. 회원가입 후 로그인합니다. 비밀번호는 8자 이상, 아이디는 영문/숫자/밑줄 4~20자입니다.
2. 지역과 관광 유형을 선택해 검색하고 상세보기 또는 지도 마커로 장소를 확인합니다.
3. 장소를 여행에 추가하고 ‘나의 여행’에서 순서·출발일·경비·상세 계획을 입력해 저장합니다.
4. Hotplace에 사진을 올리거나 여행 이야기·공지사항에 글을 작성합니다.
5. 이름을 클릭해 내 정보를 조회/수정하고 회원 탈퇴를 할 수 있습니다.

## 저장 및 범위

회원, 여행계획, Hotplace, 게시글, 공지는 브라우저 localStorage에 저장하며 로그인 세션은 sessionStorage에 저장합니다. 비밀번호는 임의 salt와 SHA-256 해시로 저장합니다. 이는 과제용 클라이언트 구현으로, 서버 인증·사용자 간 동기화·실제 이메일 본인인증을 제공하지 않습니다. 비밀번호 찾기는 아이디와 이메일 확인 방식의 학습용 구현입니다. 공지사항은 로그인한 회원이 등록하며 본인이 작성한 공지만 수정/삭제할 수 있습니다. 탈퇴 시 회원정보와 개인 여행계획은 삭제되고 작성한 공개 글은 남습니다.

F106 뉴스 크롤링/DB 저장과 선택 예시 F111~F114(날씨·사진 추천·일출/일몰·충전소)는 구현하지 않았습니다. API 제공 사진은 장소 카드와 상세에 표시합니다. 경로는 방문 순서 계획이며 실제 도로 길찾기·최단 경로 계산 기능은 없습니다. Hotplace는 외부 카카오맵 검색으로 위치를 확인합니다.

## 파일 구조

- `index.html`: 메인 화면, 탐색/계획/Hotplace/게시판/공지/내 정보
- `css/style.css`: 반응형 디자인
- `js/main.js`: DOM, 회원/여행/게시판 로직
- `js/api.js`: 관광공사 API 요청
- `js/data.js`: 지역/유형 목록과 샘플 데이터
- `01_api/`: 제공된 API 실습 예제 (지도 미완성 및 키 export 수정)
- `docs/screenshots/`: 실행 화면 캡처
- `docs/verification.md`: 검증 결과
